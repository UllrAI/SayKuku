# 执行首轮渠道发布并按真实反馈迭代

## 背景

首轮素材与平台草稿在 `marketing/`，但渠道账号、发布时间、公开链接和真实用户反馈尚未确定。按 `marketing/strategy/channels.md` 分阶段发布，避免同文跨平台刷屏。

## 完成标准

- [ ] 公开试用入口就绪后，先发朋友圈与小红书图文；记录每帖 URL、素材版本与用户提问。
- [ ] 公众号补充完整权限、Qwen 配置与费用说明；对 `say.anikuku.com` 的 HTTPS 与站内链接逐个核验。
- [ ] V2EX 以兼容性问题为中心发帖；Product Hunt 仅在英文页面和可试用安装包就绪后提交，并由 maker 回答评论。
- [ ] 每个平台记录曝光、收藏/评论、入口点击（可测时）、实际试用和可复现故障；不凭点赞数下结论。
- [ ] T+7 汇总前 3 个用户疑问和前 3 个兼容问题，更新 FAQ 与下一轮内容。引用评价前征得授权。
