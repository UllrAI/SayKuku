# Typeless 降低额度后，我给自己做了一个 Mac 语音输入工具

![SayKuku 宣传图：按 Fn 语音输入，连按两次 Fn 唤起 Voice Agent](https://say.anikuku.com/assets/wechat-cover.png)

我之前用 Typeless 做语音输入。额度降低后，试了几款替代品，总觉得和自己的输入习惯差一点。写消息时，我常常已经想好整句，光标也停在输入框里；这时最想做的事，就是直接开口，把话写到那里。于是我 Vibe Coding 了一个 Mac 工具，叫 SayKuku。

## 光标在哪儿，就在哪儿说

SayKuku 的语音输入从 Fn 开始。光标停在聊天窗口、邮件或文档里，按 Fn 说话，结束后识别结果会尝试写回原来的位置。你可以在设置里选择按住 Fn 说，也可以单击开始、再次单击结束；如果 Fn 与系统动作冲突，还能配置普通的全局快捷键。

这样，写到一半的消息仍在眼前，话说完就可以接着修改、发送。不同 App 的文本控件实现并不一致，SayKuku 会在写回前核对目标，但不能保证每个输入框的表现完全相同。重要内容发出前，最好再看一眼识别结果，尤其是人名、项目名和数字。

## 双击 Fn，说出你的要求

连按两次 Fn，就会进入 Voice Agent，不用先选中文字。想问一个问题，可以直接开口；想写一段内容，可以在输入框里说“帮我写一句回复，说明周四上午可以”，也能接着上一轮对话聊。即使停在桌面、没有输入光标，也能直接提问，回答会留在卡片里。

有时一句话已经写出来，只是太长，或者语气不合适。这时选中它，连按两次 Fn，再说“短一点”或“翻成自然的英文”。选区是这次要处理的内容；Voice Agent 还会结合你允许的上下文工作。语音输入和 Voice Agent 用不同手势，不用先打开一个窗口再选模式。

我还做了一个简单的记忆页，放常用人名、项目和术语。可以手动添加，从粘贴的文字中挑选，也可以在听写后确认一条纠正建议。保存的词条随时能编辑或删除；它们是识别时的参考，不会替你补写没说过的内容。

SayKuku 是用 SwiftUI 和 AppKit 做的原生 macOS 应用，支持 macOS 15 及更新版本。1.0.2 的通用 DMG 只有 4.8 MB，Apple 芯片和 Intel Mac 都可以安装。App 本身免费，源代码已在 github.com/UllrAI/SayKuku 公开。

## 使用前需要配置什么

首次使用需要授予麦克风和辅助功能权限，并填入自己的阿里云百炼 Qwen API Key。麦克风用于你主动开始的语音输入和 Voice Agent；辅助功能用于识别 Fn 手势、读取选中文字，以及把结果写回当前 App。API Key 保存在系统钥匙串里。

填写业务空间 ID 后，默认用 Qwen3.8 Omni Flash Realtime 做实时听写；没有填写时，会在录音结束后用 Qwen3.8 Omni Flash 做批处理识别。Voice Agent 也使用 Qwen3.8 Omni Flash。它让模型直接理解音频，不采用固定的“先用纯 ASR 转文字，再交给另一个模型处理”的两段流程。语音会发往你选择的 Qwen 地域，因此使用时需要联网。Voice Agent 可以结合选区和你允许的上下文工作；当前 App、窗口信息、屏幕上的文字等来源可以在设置里调整。普通语音输入不会读取屏幕文字。

模型调用由自己的 API Key 账号计费。按阿里云当前北京地域的价格估算，默认实时模型 **1 小时音频输入约 0.15 元**。输出文字、Voice Agent 请求、其他模型或地域会产生不同费用，实际以自己的账单为准。也可以先查看账号是否有适用的免费额度。这里说的“免费”，指 SayKuku App 本身，不包括模型服务。

输入历史、记忆和可选录音保存在这台 Mac 上，本地文件没有额外加密；不想保存新的输入历史，可以在设置里选择“不保存”。官网首页有一段可点击的 Fn 交互演示，使用预设文字，不会打开麦克风或调用模型。真正使用前，你可以先在官网查看配置、权限和隐私说明。
