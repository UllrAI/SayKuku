# 写消息时，我想先说完再打字

写消息写到一半，常有一种不太划算的停顿：我知道接下来要说什么，却还在键盘上把它一个字一个字拼出来。

于是做了 SayKuku。它是 Mac 上的语音输入工具。光标停在输入框里，按 Fn 开始说，结束后文字尝试回到原来的位置。不需要先打开另一个窗口，复制完再切回来。

但说话不只是输入。已经写下的句子，有时需要改短一点、换个语气，或者翻成英文。选中文字后连按两次 Fn，进入 Voice Agent，再说出要求。它也可以回答问题，或接着上一轮对话继续。Fn 负责输入，Fn Fn 负责让 Agent 做下一步，这两个动作分得很清楚。

官网做了一个小演示：页面上的 Fn 可以点，切到 Voice Agent 也能看一段预设的翻译和追问。这个网页演示不使用麦克风，也不调用模型；只是让你在安装前先理解交互。

我还保留了一个很轻的「记忆」页。常用人名、项目名和术语，可以自己加，或从粘贴的文字里挑选；听写后确认的纠正也可以记住。想改或删除，回到记忆页就能处理。

有几件事要先讲明白。SayKuku 目前只支持 macOS 15+，需要麦克风和辅助功能权限。当前版本使用 Qwen 处理语音与 Voice Agent 请求，因此还需要你自己的 API Key，模型服务可能收费。语音和你允许的 Agent 上下文会发往所选地域；历史、记忆和可选录音保存在本机，文件没有额外加密，API Key 放在系统钥匙串。想逐项查看，可以读官网的[隐私与权限说明](https://say.anikuku.com/privacy/)。

1.0.1 已放到 [say.anikuku.com 的版本下载区](https://say.anikuku.com/#download)，也可以先看页面上的预设演示。试用后，我最想知道的不是“好不好看”，而是：你在哪个 App 里输入最多？哪一步会让你停下来？
