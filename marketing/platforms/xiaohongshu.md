## 01 首发

**标题：** Typeless 降低额度后，我做了个 4.8M 的 Mac 语音工具

**配图：** `../assets/generated/xhs-launch-cover.png`；第二张可用 `../assets/screenshots/quick-start.png`，标注“开发版真实界面”。

**正文：**

之前一直用 Typeless，额度降低后换着试了几个，还是不太合手。索性 Vibe Coding 了 SayKuku，先把自己最常用的两个动作做好。

光标停在哪个输入框，就按 Fn 说话，文字会尝试写回那里。连按两次 Fn，说出你的要求：不选文字也能直接问问题、起草内容。想改已有的句子，再选中它，说“短一点”或“翻成英文”。

它是原生 macOS App，1.0.2 安装包只有 4.8 MB。App 免费；使用时自己配 Qwen API Key，模型费用走自己的账号。源代码已在 github.com/UllrAI/SayKuku 公开。

官网能下载，也有一个不用麦克风的预设交互演示。你最想让我测哪个 Mac App 的输入框？

**标签：** #Mac效率工具 #语音输入 #独立开发 #macOS

**置顶评论：** 下载和隐私说明：say.anikuku.com。需要 macOS 15+；模型调用由自己的 Qwen Key 计费。网页演示不是实时识别。

## 02 费用与隐私

**标题：** 免费的语音输入 App，要自己付多少模型费？

**配图：** `../assets/generated/xhs-privacy-card.png`。

**正文：**

SayKuku App 本身免费，使用时需要自己填阿里云百炼 Qwen API Key。它用 Qwen3.8 Omni Flash 系列直接处理音频和指令，不是固定先做纯 ASR、再调用第二个模型。

按官方当前北京地域价格估算，默认实时模型的 1 小时音频输入约 0.15 元。输出文字、Agent 请求和不同地域另计；实际账单取决于你怎么用，也可能有适用的免费额度。

语音会发往所选 Qwen 地域。历史、记忆和可选录音留在 Mac 上，本地文件未额外加密；API Key 存系统钥匙串。Voice Agent 的上下文来源可以在设置里调整。完整说明在 say.anikuku.com/privacy/。

## 03 场景帖

**标题：** 写英文邮件卡住时，我直接对选中的句子说“自然一点”

**正文：**

写邮件时，有时意思已经有了，英文语气还想再顺一点。我会先选中那句，连按两次 Fn，再说“改成自然一点的英文”。

双击 Fn 就能进入 Voice Agent，不选文字也能提问或说“帮我写一封邮件，约周四上午见面”。只想把话写下来，就用普通 Fn 语音输入。结果出来后我会再看一眼措辞和事实，尤其是发给别人的内容。

你更想用它写邮件、回消息，还是整理文档？
