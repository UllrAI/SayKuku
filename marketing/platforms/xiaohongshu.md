## 01 首发

**标题：** Mac 上，按 Fn 说完直接写进输入框

**配图：** `../assets/generated/xhs-launch-cover.png`；第二张可用 `../assets/screenshots/quick-start.png`，标注“开发版真实界面”。

**正文：**

写消息时，脑子里已经是完整的一句，手还在慢慢敲第一个词。最近做 SayKuku，就是想把这个小停顿省掉。

光标留在输入框，按 Fn 说话，文字就尝试写回那里。选中一段文字，连按两次 Fn，就能叫出 Voice Agent：说“短一点”“翻成英文”，也能问个问题，再接着聊。

它是 macOS 15+ 的原生 App。现在的版本需要自己配置模型 API Key，语音会在云端处理；官网把权限和数据去向写清楚了。1.0.1 可以从官网下载；网页还放了一个不用麦克风的预设交互演示。

你最想在微信、邮件、浏览器，还是写文档时用？我想先把大家最常用的输入框测好。

**标签：** #Mac效率工具 #语音输入 #独立开发 #macOS

**置顶评论：** 1.0.1 下载、预设交互演示和隐私说明都在 say.anikuku.com。网页里的 Fn 不会访问麦克风；你想看哪个 App 的真实实测，评论告诉我。

## 02 隐私与门槛

**标题：** 语音输入前，我也想先知道声音去哪儿

**配图：** `../assets/generated/xhs-privacy-card.png`。这里可以明确写当前服务方 Qwen，因为是数据去向说明。

**正文：**

用语音工具，我会先看两件事：声音发往哪里，历史留在哪里。

SayKuku 当前用 Qwen 处理语音，得联网，也得自己配 API Key。历史、记忆和可选录音留在本机，但这些文件没有额外加密；API Key 在系统钥匙串。Voice Agent 可能用到选中文字和你允许的窗口内容，来源可以在设置里调整。

辅助功能权限是为了识别 Fn、读取选区和把文字写回去。如果你需要完全离线的工具，它现在不合适。完整说明在 say.anikuku.com/privacy/。

改写完我会读一遍，看看语气对不对，事实有没有跑偏。收件人也得自己看清楚。
