## 第一轮内容主线

- 场景 A：聊天时想到一句完整的话，按 Fn 直接说到光标处。
- 场景 B：不选文字，连按两次 Fn，直接提问或在空输入框里说「帮我写一句回复，说明周四上午可以」。再展示选中一段回复，说「更简洁一点」的编辑场景。
- 场景 C：常用人名和项目名，确认后加入记忆。
- 场景 D：用户最关心的隐私与配置成本。明确 Qwen 云端处理、API Key 自备和本机保存范围。

首发先讲 Typeless 降低额度后的个人起因、`Fn Voice Input / Fn Fn Voice Agent`，并交代 App 免费、自备 Qwen API Key。记忆、费用和隐私分别做后续解释帖。二次分发时更换开头、图片顺序和评论区问题，不复制平台间的正文。

## 建议节奏

- T-7 至 T-1：检查公开入口与截图；邀请少量真实 Mac 用户试用并记录原话。没有许可不引用他们的话。
- T0：官网版本区和 R2 安装包先可访问，再发朋友圈和小红书；当日答疑。
- T+1 至 T+3：公众号详解、V2EX 求反馈；按评论补充 FAQ。
- T+7：若英文页面与演示齐备，发布 Product Hunt；持续回复评论。
- T+14：复盘入口点击、安装/首次配置、首次成功写入、7 日留存。若尚无数据采集，先用可数的下载与问卷反馈，不编造转化率。

## 平台依据与注意

- [Product Hunt 官方准备清单](https://www.producthunt.com/launch/preparing-for-launch)：方形缩略图建议 240×240，至少两张 gallery 图，gallery 建议 1270×760；描述最多 500 字符；maker 首评要具体。正式提交时再核对页面字段。
- [Product Hunt 官方指南](https://www.producthunt.com/launch)：可自己提交，分享时可请人访问和评论，不要请求直接 upvote。
- [V2EX About](https://v2ex.com/about)：社区以分享、探索和讨论为主；帖子提供实现细节与明确反馈问题，避免只投广告语。
- 小红书与微信上传规格会变动，且官方公开文档不完整。本包以常见易读比例出图（小红书 1080×1440、横图 1200×675、公众号封面 900×383），**上传时以平台编辑器即时提示为准**。不把经验尺寸写成平台硬性规则。
